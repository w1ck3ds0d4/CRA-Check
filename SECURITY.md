# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
**private vulnerability reporting**: open the repository's **Security** tab and
choose **Report a vulnerability** (Security Advisories). This keeps the report
confidential until a fix is available.

Please do not open a public issue for security problems.

## What to expect

- We aim to acknowledge a report within a few business days.
- Once triaged, we will work on a fix and coordinate a disclosure timeline with
  you.
- Fixes are shipped as a new release; the advisory is published once users have
  had a reasonable window to update.

## Scope

This policy covers the `cra-check` Action and the `cra_report.py` evidence
generator in this repository.
